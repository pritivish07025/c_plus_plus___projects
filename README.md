## 💻 How to Run the Projects

### 1. Clone the Repository

```bash
git clone https://github.com/pritivish07025/c_plus_plus___projects.git
```

### 2. Navigate to the Repository

```bash
cd c_plus_plus___projects
```

### 3. Open a Project

Choose any project folder:

```bash
cd cinema-seat-booking-system
```

### 4. Compile the C++ Program

Using `g++`:

```bash
g++ main.cpp -o main
```

### 5. Run the Program

**Windows:**

```bash
main.exe
```

**Linux / macOS:**

```bash
./main
```

> Note: The exact source filename may differ between projects.
